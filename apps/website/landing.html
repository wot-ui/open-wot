CLI / 组件知识

在终端查询真实 wot-ui 数据。

wot --help
wot list [keyword]按名称、中文名、标签、分类或描述查找组件
wot info <component>查询 props、events、slots 和 CSS 变量
wot doc <component>获取完整 Markdown 组件文档
wot demo <component> [name]查看示例列表或指定 demo 源码
wot token [component]查询全局或组件 CSS 变量
wot changelog [version] [component]按版本或组件查看更新记录
wot usage [dir]统计项目中的 wd-* 组件使用情况
wot lint [dir]检查未知组件、空按钮等使用问题
示例wot info Button --version 2.0.4 --format markdown

SAFE WRITE / 保守写入

修改配置，但不破坏用户内容。

--dry-run
01先计算计划

写入前生成 ChangePlan，可先预览再执行。

02幂等与原子写入

重复初始化不会重复插入，失败时自动回滚。

03保留已有配置

保留已有 Server、JSONC 注释与非托管 TOML。

04安全失败

遇到非法或无法安全接管的结构时直接停止。

版本解析顺序

不指定版本，也能找到正确答案。

查询命令支持 --format text|json|markdown。结构化结果写入 stdout，诊断信息保持在 stderr。

  1. 01项目已安装版本优先读取真实安装结果
  2. 02依赖声明版本其次读取 package.json 范围
  3. 03最新离线数据未检测到版本时安全回退
